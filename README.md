

The To-Do List is a simple and responsive web application developed using HTML, CSS, and JavaScript. It helps users organize their daily activities by allowing them to add, manage, complete, and delete tasks.

This project was developed as part of my JavaScript and DOM manipulation learning journey to improve my practical programming skills.

## Features

- Add new tasks.
- Display tasks dynamically.
- Mark tasks as completed.
- Delete tasks from the list.
- Interactive buttons.
- Simple and user-friendly interface.
- Responsive design for different screen sizes.

## Technologies Used

- **HTML5:** Used to structure the application.
- **CSS3:** Used to style the application and create a responsive layout.
- **JavaScript:** Used to implement functionality and handle user interactions.
- **DOM Manipulation:** Used to dynamically create, update, and remove HTML elements.

## Lessons Learned

During the development of this project, I gained practical experience in the following areas:

1. **HTML Structure:** Learned how to organize a web page using semantic HTML elements.
2. **CSS Styling:** Improved my understanding of CSS selectors, classes, IDs, spacing, colors, and responsive layouts.
3. **JavaScript Fundamentals:** Practiced variables, functions, conditional statements, and event listeners.
4. **DOM Manipulation:** Learned how to select HTML elements using `querySelector()` and dynamically create elements using `createElement()`.
5. **Event Handling:** Learned how to respond to user actions such as clicking buttons and submitting forms.
6. **Problem-Solving:** Improved my ability to identify errors, debug code, and find solutions.
7. **Git and GitHub:** Practiced using Git commands to track changes and upload projects to GitHub.

## Challenges Faced

While developing the To-Do List application, I encountered several challenges:

1. **DOM Manipulation:** Understanding how to dynamically add and remove HTML elements using JavaScript was challenging at first.

2. **Event Listeners:** Learning how to connect button clicks and form submissions to JavaScript functions required practice.

3. **Task Management:** Ensuring that tasks were added, completed, and deleted correctly required careful handling of DOM elements.

4. **CSS Styling:** Making the application visually appealing and responsive across different screen sizes required additional adjustments.

5. **Debugging:** Identifying syntax errors and fixing JavaScript functionality issues helped me improve my debugging skills.

## Solutions to the Challenges

- Practiced selecting and manipulating DOM elements.
- Used `addEventListener()` to handle user interactions.
- Tested individual JavaScript functions before combining them.
- Used browser developer tools to identify and fix errors.
- Improved the CSS layout through continuous testing.
